## 🌟 Featured Projects

### 🌿 [Leafy AI Companion](https://github.com/mtheusantunes/leafy-ai-companion)

> **Embodied AI • 100% Local LLM • Edge Computing • LangChain & Weaviate**

An affective and intelligent botanical companion plant engineered with physical computing principles.

- **Privacy by Design**: Runs 100% offline via **Docker + Ollama (Qwen2.5 / Llama 3.1) + Weaviate**, ensuring zero cloud dependency and strict data privacy.
- **Hierarchical RAG**: Multi-stage document chunking with **Docling** and semantic vector indexing.
- **IoT & Hardware**: Dedicated client running on **Raspberry Pi** with USB microphone voice capture, TTS audio synthesis, and interactive **Streamlit** dashboard.

---

### 🔍 [ChatRAG](https://github.com/mtheusantunes/ChatRAG)

> **Retrieval-Augmented Generation (RAG) • LangChain • Vector Search**

Modular document-grounded AI assistant for contextual question-answering over educational PDF libraries.

- Extracting and chunking documents with **PyPDFLoader** and LangChain text splitters.
- High-performance semantic retrieval using **Weaviate** and **HuggingFace** embeddings.
- Context synthesis powered by local **Llama 3** inferencing through Ollama.

---

### 🎓 [IFCODES](https://github.com/ProjetoIntegradorIFMOC/ifcodes)

> **Automated Code Evaluation Platform • Tech Lead & QA • React & Laravel**

Educational judge and automated testing platform for computer science students.

- Led technical team architecture, Agile task distributions, and milestone deliveries.
- Engineered comprehensive Quality Assurance (QA) test suites and documentation.
- Decoupled modern frontend in **React** backed by a robust **PHP Laravel** API and **Docker** orchestration.

---

### 🎮 [Rock Paper Scissors Shallow Learner](https://github.com/mtheusantunes/RPS-Shallow-Learner)

> **Classical Machine Learning • Markov Chains • Java**

Predictive game agent leveraging **Conditional Probability** and dynamic transition matrices to model human opponent behaviors in real time, demonstrating high interpretability and efficiency without the overhead of deep neural networks.
